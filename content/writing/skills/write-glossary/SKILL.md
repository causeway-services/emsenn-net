---
description: Create a glossary that defines every term used in a document in plain language. Use when a document introduces specialized vocabulary.
date-created: 2025-04-01
---

- List every non-common term introduced in the document.
- For each term, write a one- to three-sentence definition in plain language.
- Add any symbols or notation used alongside the term.
- Remove circular definitions; each term should be understandable on its own.
- Place the glossary adjacent to the document and link to it.
