# Agent Log Guidance

Agent logs are written for other agents of equal or greater capacity. Use them to record reasoning, decisions, and next actions when creating new content or ideas.

## When to write a log

- When thinking through new content, ideas, or plans.
- When making structural decisions that affect multiple files.
- When a decision is made that another agent will need to understand later.

## Audience

Write for another agent who did not witness the work. Assume they can read the repository but do not assume they know the reasoning.

## Required sections

- Summary
- Decisions
- Open questions
- Next actions

## Quality checks

- Reference key files or directories touched.
- Capture any unresolved gaps or dependencies.
- State assumptions made during the work.
