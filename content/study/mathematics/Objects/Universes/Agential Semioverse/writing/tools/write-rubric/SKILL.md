- Define the purpose and the decision the rubric supports.
- List 3–7 criteria with plain-language names.
- For each criterion, define levels or scoring with observable descriptions.
- Avoid vague terms like "good" without a measurable definition.
- Use the rubric template if appropriate: [rubric template](/mathematics/objects/agential-semioverse/tools/markdown-templates/templates/rubric.md.j2).
