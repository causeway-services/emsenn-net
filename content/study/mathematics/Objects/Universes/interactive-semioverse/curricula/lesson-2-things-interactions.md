# Things and Interactions

The interactive semioverse introduces things as external handles and defines a
calculus of interactions that generate semantic material.

## Thing handles

A thing handle is a persistent name for a thing. It is not itself an element of
the semantic domain; it is mapped into the domain by a seed function.

## Interaction terms

Interaction terms are built from thing handles and definable operators. Their
interpretation produces elements of the semantic domain.

## Interaction surfaces

An interaction surface assigns a finite set of interaction terms to each thing.
This surface is the interface used to build fragments for the thing.
