# Planning Ideas

## Multichoice 

- Skills for having agents lint and create a multi-choice todo list for what changes would fix it.

i.e.

```md
- Conflict between ID (foo) and kind (readme) in `file`
  - [ ] Change ID to foo-readme
  - [ ] Change kind to thing
```
