- Define the reader persona using [define-reader-persona](/media/writing/tools/define-reader-persona/SKILL.md).
- Apply [emstyle-voice](/media/writing/tools/emstyle-voice/SKILL.md).
- If the audience is general, apply [plain-language-writing](/media/writing/tools/plain-language-writing/SKILL.md).
- Avoid acronyms unless the acronym has been explicitly approved for use in the piece.
- Keep claims scoped: state assumptions before conclusions.
- If the text is mathematical, apply [math-for-mathematicians](/media/writing/tools/math-for-mathematicians/SKILL.md) or [math-for-general-audience](/media/writing/tools/math-for-general-audience/SKILL.md).
- When referencing files, use Markdown links, not monospaced paths.
