- Read the plain-language specification at [/media/writing/practice/plain-language.md](/media/writing/practice/plain-language.md).
- Use the default audience unless an "Assumed audience" section is required.
- Put the main point in the first screen of the page.
- Define technical terms on first use and use them consistently.
- Avoid acronyms unless they are explicitly approved and defined on first use.
