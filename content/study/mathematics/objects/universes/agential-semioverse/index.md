An ***agential semioverse*** is a [[mathematical universe]] based on an [[Interactive Semioverse]], but with internal [[agent|agents]].

It's created specifically to help bridge the gap between semioverses and modern computing, so this folder also contains information about what an agential semioverse implemented with [[Markdown]] and so on looks like.
