# Content Type Schemas (Semioverse)

Canonical JSON schemas for common Markdown content types. These are used by validation tools and pipelines to ensure consistent frontmatter/layout.

Module guidance: modules should include `GENEALOGY.md` and `HISTORY.md` capturing incomplete histories and genealogies of the topic itself.
