# Semantics Glossary

## intension

A mode of presentation or sense that fixes reference under varying conditions.

## extension

The actual referent or set of referents of a term in a given world.

## primary intension

The descriptive content that picks out a referent based on epistemic conditions.

## secondary intension

The referent fixed by a term given how the world actually is.

## rigid designation

A term that refers to the same object in every possible world where it exists.
