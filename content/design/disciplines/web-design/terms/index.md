Key concepts in web design.

- [[semantic-html|semantic HTML]] — using HTML elements for their meaning, not their appearance
- [[accessibility]] — designing so that everyone can perceive, understand, navigate, and interact with web content
- [[responsive-design|responsive design]] — adapting layout and presentation to the reader's device and context
- [[linked-data|linked data]] — publishing structured data on the web so that machines can follow connections across documents
