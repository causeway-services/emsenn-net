Key concepts in web design.

- [semantic HTML](semantic-html.md) — using HTML elements for their meaning, not their appearance
- [accessibility](accessibility.md) — designing so that everyone can perceive, understand, navigate, and interact with web content
- [responsive design](responsive-design.md) — adapting layout and presentation to the reader's device and context
- [linked data](linked-data.md) — publishing structured data on the web so that machines can follow connections across documents
