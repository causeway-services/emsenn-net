# Interactive Semioverse Glossary

## thing handle

A persistent handle that refers to a thing without identifying it with a single
semantic element.

## interaction term

A term built from thing handles and definable operators, interpreted into the
semantic domain.

## interaction surface

The finite set of interaction terms associated with a thing in a given state.

## thing fragment

The least fragment containing the semantic interpretations of a thing's
interaction surface.

## footprint

The closure of a thing fragment using the state's operators; a closed partial
state associated with the thing.

## delta

A comparison operation that measures the difference between interaction surfaces,
fragments, or footprints.

## subtraction

A Heyting-style removal operation that deletes semantic influence relative to a
fragment.
