# GFRTU Tests

These tests are manual checks against the toy model.

1. Verify the trace category is small and finite.
2. Verify each fiber is a Heyting algebra.
3. Verify stabilizer and drift are monotone and commute.
4. Verify fixed fibers match the example.
5. Verify the closure sequence matches `goldens/toy-trace-universe-closure.md`.
