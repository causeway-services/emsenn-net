# Profile Trace

## Interpretation

Profiles inherit trace structure, but we must explicitly record the trace witnessed inside a profile.  *Complete Trace* witnessing *Profile Recognitions* yields ***Trace Profile*** ([TraceProfile](trace-profile.md)).

Using earned recognitions, this composition threads the trace through the profile-stable recognitions, so *Trace Profile* is established.
