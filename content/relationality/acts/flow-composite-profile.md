# Composite Profile Flow

## Interpretation

The global flow restricts to the composite profile.  *Flow* witnessing *Profile Composite* yields ***Flow Composite Profile*** ([FlowCompositeProfile](flow-composite-profile.md)).

Composing the flow with the composite profile records the induced dynamics, so *Flow Composite Profile* follows.
