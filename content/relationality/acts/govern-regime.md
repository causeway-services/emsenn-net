# Governing Regime

## Interpretation

A discipline alone does not specify which recognitions it stabilizes.  *Fix *Flow* Nucleus* witnessing *Discipline* produces ***Govern Regime*** ([GovernRegime](govern-regime.md)).

This composition records the recognitions fixed by the discipline, using only symbols we've already earned, so *Govern Regime* follows.
