# Implying Recognition

## Interpretation

Implication transforms recognitions: whenever one holds, another must follow.  *Join Recognition* witnessing *Form Function Term* produces ***Imply Recognition*** ([ImplyRecognition](imply-recognition.md)).

*Form Function Term* already presents named transformations; composing it with joins records the internal implication, so *Imply Recognition* is earned.
