# Concept Module Specifications

Concept modules organize theory, practice, and tools around a named concept.
They are a way of understanding the structure of the library itself.

## Required files

- `README.md`
- `SPECIFICATIONS.md`
- `GLOSSARY.md`
- `GENEALOGY.md`
- `HISTORY.md`

## Recommended structure

- `curricula/` for lessons and learning sequence.
- `skills/` for operational skills and scripts.
- `theory/` for formal or conceptual documents.
- `practice/` for methods, procedures, and exercises.
- `tools/` for software or instrumentation details.
- `IDEAS.md` and `PLANS.md` for concept-level work queues.

## Intension notes

Concepts should record both primary and secondary intension where relevant,
using semantics data as the basis for secondary intension.
