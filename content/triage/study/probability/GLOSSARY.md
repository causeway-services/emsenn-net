# Probability Glossary

- **conditional probability**: The probability of an event given another event.
- **event**: A subset of the sample space.
- **independence**: A relationship where one event does not affect another.
- **likelihood**: The probability of evidence given a hypothesis.
- **prior**: A probability assigned before observing new evidence.
- **posterior**: A probability updated after observing new evidence.
- **probability**: A number between 0 and 1 assigned to an event.
- **sample space**: The set of all possible outcomes.
