# Markdown Glossary

## markdown file

A plain-text document using markdown syntax plus optional YAML frontmatter.

## frontmatter

The YAML metadata block at the top of a markdown file, delimited by `---`.

## vault

A collection of markdown files treated as a linked knowledge base.

## note

A single markdown file within a vault, often treated as a thing or node.

## link

A reference from one markdown file to another, often encoded as a path.
