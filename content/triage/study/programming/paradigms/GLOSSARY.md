# Programming Paradigms Glossary

- **declarative**: Describe what should be computed, not how to compute it.
- **imperative**: Specify step-by-step commands that change state.
- **logic programming**: State rules and let the system derive conclusions.
- **event-driven**: React to events or messages as they arrive.
- **dataflow**: Model computation as data moving through a graph of operations.
