# Object-Oriented Programming Glossary

- **class**: A blueprint defining data and behavior for objects.
- **object**: An instance of a class with its own state.
- **encapsulation**: Keeping internal state private and exposing a defined interface.
- **inheritance**: Defining new classes based on existing ones.
- **polymorphism**: Treating different object types through a common interface.
