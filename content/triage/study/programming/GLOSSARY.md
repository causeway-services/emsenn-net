# Programming Glossary

- **algorithm**: A finite procedure for transforming inputs into outputs.
- **bug**: A defect that causes a program to behave incorrectly.
- **data structure**: A way of organizing data for efficient access or updates.
- **function**: A named operation that maps inputs to outputs.
- **module**: A unit of code that groups related functionality.
- **program**: A sequence of instructions executed by a machine.
- **variable**: A named reference to a value that may change.
