# Modal Logic Glossary

## Modal operator

A symbol that modifies a proposition to express necessity or possibility.

## Necessity

The modality expressed by $\Box$, meaning "true in all accessible worlds."

## Possibility

The modality expressed by $\Diamond$, meaning "true in some accessible world."

## Kripke frame

A pair $(W,R)$ of worlds $W$ and an accessibility relation $R$.

## Kripke model

A Kripke frame plus a valuation of atomic propositions at each world.

## Accessibility relation

A relation describing which worlds are reachable.

## Possible world

A state used to evaluate modal truth.

## Modal system

A set of axioms governing modal logic.
