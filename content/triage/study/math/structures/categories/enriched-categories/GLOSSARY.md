# Enriched Categories Glossary

## monoidal category

A category equipped with a tensor product, a unit object, and coherence data for
associativity and units.

## enriched category

A category whose hom-objects live in a fixed monoidal category instead of a set.

## hom-object

The object in the base monoidal category that plays the role of morphisms between
two objects in an enriched category.

## tensor product

The binary operation in a monoidal category used to compose hom-objects.

## unit object

The object that acts as a tensor identity in a monoidal category.
