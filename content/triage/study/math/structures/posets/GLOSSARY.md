# Posets Glossary

## Preorder

A relation that is reflexive and transitive. It allows ties that are not necessarily equal.

## Partial order

A preorder that is also antisymmetric, so ties imply equality.

## Lattice

A partial order where every pair of elements has a meet and join.

## Reflexive

Every element is related to itself.

## Transitive

If $a \leq b$ and $b \leq c$, then $a \leq c$.

## Antisymmetric

If $a \leq b$ and $b \leq a$, then $a=b$.

## Meet

The greatest element that is below both elements.

## Join

The least element that is above both elements.
