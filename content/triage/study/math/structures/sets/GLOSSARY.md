# Sets and Relations Glossary

This glossary defines the words used in the sets and relations lessons in plain language.

## Set

A collection of distinct items. You can decide for any candidate item whether it is in the collection.

## Element

An item that may or may not belong to a set.

## Relation

A list of ordered pairs that says which items are related to which.

## Function

A rule that assigns exactly one output to each input.

## Ordered pair

A two-item list where order matters, written $(x,y)$.

## Domain

The set of allowed inputs for a function.

## Codomain

The set of possible outputs for a function.

## Subset

A set whose elements all belong to another set.

## Union

The set of elements in either of two sets.

## Intersection

The set of elements common to two sets.
