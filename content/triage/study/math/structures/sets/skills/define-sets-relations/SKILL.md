# Define Sets and Relations

- Specify the underlying set with explicit membership criteria.
- If defining a relation, write the rule `R(a, b)` and list its domain and codomain.
- If defining a function, verify each input has exactly one output.
- Record any assumptions about equality or equivalence used in the definition.
