# Prealgebra Glossary

## magma

A set equipped with a single binary operation with no axioms imposed.

## semigroup

A magma whose operation is associative.

## monoid

A semigroup with an identity element for the operation.

## identity element

An element `e` in a magma such that `e * a = a` and `a * e = a` for all elements `a`.

## homomorphism

A function between algebraic structures that preserves the operation.
