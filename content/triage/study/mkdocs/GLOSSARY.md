# MkDocs Glossary

## mkdocs site

A static site generated from markdown files and a MkDocs configuration file.

## nav

The navigation structure that selects which pages are surfaced and how they are ordered.

## theme

The visual and layout layer for the site, including templates and styling.

## plugin

A MkDocs extension that transforms content or adds site features during build.

## semioverse surface

A readable interface that exposes semiotic structures through pages, links, and metadata.
