# Transporting Binder

## Interpretation

The seed gives a binder in isolation but not its transport through arbitrary contexts.  Forcing *Recognize Context* to witness *Binder Seed* yields ***Binder Transport*** ([BinderTransport](binder-transport.md)).

This composition shows how binders move using only earned recognitions, so *Binder Transport* follows.
