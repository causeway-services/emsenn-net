# Physics State

## Interpretation

Within such a system we need the recognitions that count as states.  *Profile Recognitions* witnessing *Flow Profile* yields ***Physics State*** ([PhysicsState](physics-state.md)).

Composing the profile with its inherited flow records the recognitions stabilized as states, so *Physics State* is valid.
