# Profile Flow

## Interpretation

The profile must inherit the flow restricted to its stable recognitions.  *Flow* witnessing *Profile Recognitions* yields ***Flow Profile*** ([FlowProfile](flow-profile.md)).

Composing the global flow with the profile uses only earned recognitions and records the induced dynamics, so *Flow Profile* is valid.
