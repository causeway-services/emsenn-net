# Progressing Typing

## Interpretation

Closed typed terms are either values or can step.  *Recognize Value* witnessing *Judge Typing* produces ***Progress Typing*** ([ProgressTyping](progress-typing.md)).

This composition states that a judgement in the empty context is either witnessed as a value or advances along the step trace, so *Progress Typing* is valid.
