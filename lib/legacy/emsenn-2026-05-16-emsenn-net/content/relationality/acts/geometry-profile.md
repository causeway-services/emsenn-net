# Profile Geometry

## Interpretation

Combining the restricted flow and nucleus yields the profile’s relational geometry.  *Flow Profile* witnessing *Nucleate Profile* produces ***Geometry Profile*** ([GeometryProfile](geometry-profile.md)).

This composition records the geometric data restricted to the profile, so *Geometry Profile* is established.
