# Tracing Judgement

## Interpretation

Observational content exists, yet we must record how such stabilized judgements evolve under evaluation.  *Stabilize Trace* witnessing *Observe Judgement* yields ***Trace Judgement*** ([TraceJudgement](trace-judgement.md)).

Using only earned stable recognitions, this composition builds the trace of judgemental acts, so *Trace Judgement* follows.
