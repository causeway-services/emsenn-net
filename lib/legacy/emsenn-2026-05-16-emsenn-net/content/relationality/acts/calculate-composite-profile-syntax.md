# Composite Profile Syntax

## Interpretation

A syntactic calculus internalizes over the composite profile.  *Judge Typing* witnessing *Composite Profile Semantics* produces ***Calculate Composite Profile Syntax*** ([CalculateCompositeProfileSyntax](calculate-composite-profile-syntax.md)).

This act records the calculus restricted to the composite domain, so *Calculate Composite Profile Syntax* is valid.
