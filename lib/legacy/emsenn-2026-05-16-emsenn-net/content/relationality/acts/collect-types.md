# Building Types

## Interpretation

The family of relational types is precisely what *Construct Types* generates.  We record this family explicitly so later sections can reference it.

The expression simply aliases the constructor’s output as ***Collect Types*** ([CollectTypes](collect-types.md)), keeping the earned structure available for future use.
