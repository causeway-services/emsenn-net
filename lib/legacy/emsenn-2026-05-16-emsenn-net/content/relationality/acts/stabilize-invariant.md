# Maintaining Invariant

## Interpretation

*Flow* fixed points that remain states represent invariants.  *Fix Flow* witnessing *Physics State* produces ***Stabilize Invariant*** ([StabilizeInvariant](stabilize-invariant.md)).

This composition uses earlier recognitions and records precisely those states fixed by the flow, so *Stabilize Invariant* follows.
