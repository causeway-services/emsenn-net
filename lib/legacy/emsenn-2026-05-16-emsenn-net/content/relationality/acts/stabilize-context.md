# Stabilizing Context

## Interpretation

*Stabilize Judgement* shows contexts only matter through the stable judgements they support, but we must identify contexts giving the same stable judgements to all stabilized terms.  *Recognize Context* witnessing *Stabilize Judgement* produces ***Stabilize Context*** ([StabilizeContext](stabilize-context.md)).

The composition uses previously earned recognitions and identifies such contexts, so *Stabilize Context* follows.
